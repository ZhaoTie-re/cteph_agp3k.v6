# Removed component: `check/down_sampling` (July 2026)

`cteph_agp3k.v6/check/down_sampling` was deleted on 2026-10-30 at the user's request and rebuilt from
scratch as `check/platform_depth`. This file records what was removed and why.

## Why it was removed

- It was built for the old `refined_core` cohort (2,193 samples), not the three current cohorts.
- It covered two regions only (chr16:53703963-54121941 and chr4:76306733-76311130); the first does not
  reach the start of the current FTO window (53,632,967).
- Its inputs no longer exist: `wgs.auto.par/results/{14,15,16}_*`, `PopGMM_output/refined_core.fid_iid.txt`,
  `analysis/assoc_rvtest`, the old `assoc_saige` result layout.
- It read CRAM paths and depths from `tmp/cram.v6/cram.v6.summary.csv`, which is stale for both.
- It re-called the down-sampled cases only, with GATK 4.6.2.0 and forced alleles (`--alleles`), while the
  cohort was discovery-called with GATK 4.1.x; controls kept their original calls.
